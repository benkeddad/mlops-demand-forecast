# MLOps Pipeline Deployment

This repository contains an automated deployment pipeline that orchestrates a full MLOps stack (PostgreSQL, Redis, MLflow, Prefect, and a Rossmann FastAPI application) using Kubernetes (K3s) on Windows.

## Complete Setup Guide (From Scratch)

If you are setting this up on a fresh Windows machine, you must follow these steps **in order** before running the deployment script.

### Step 1: Install WSL and Ubuntu on Windows

Open **PowerShell as Administrator** and run the following commands to install the Windows Subsystem for Linux and the official Ubuntu distribution:

```powershell
# Install WSL and Ubuntu
wsl --install -d Ubuntu

```

*Note: This process may require a computer restart. Once installed, an Ubuntu terminal will open asking you to create a UNIX username and password. Remember this password; you will need it for `sudo` commands.*

Once Ubuntu is installed, ensure it is set as your default WSL distribution by running this in PowerShell:

```powershell
# Set Ubuntu as the default WSL environment
wsl --set-default Ubuntu

```

### Step 2: Install and Configure Docker (Via Docker Desktop)

Because you are on Windows, Docker is managed by **Docker Desktop**, which will automatically bridge the `docker` command directly into your Ubuntu environment.

1. Download and install [Docker Desktop for Windows](https://www.docker.com/products/docker-desktop/).
2. During installation, ensure the **"Use WSL 2 instead of Hyper-V"** option is checked.
3. Open Docker Desktop.
4. Click the **Settings (Gear Icon)** in the top right.
5. Navigate to **Resources > WSL Integration**.
6. Ensure the toggle next to **Ubuntu** is turned **ON**.
7. Click **Apply & Restart** in the bottom right.

### Step 3: Install Python, K3s, and Terraform inside Ubuntu

Now, open your **Ubuntu terminal** (search for "Ubuntu" in your Windows Start menu) and run the following blocks of commands to install all necessary programming and infrastructure tools.

**1. Install Python 3 and Core Build Tools:**

```bash
# Update the package list and install Python, pip, and virtual environment tools
sudo apt-get update && sudo apt-get upgrade -y
sudo apt-get install -y python3 python3-pip python3-venv build-essential

```

**2. Install K3s (Kubernetes):**

```bash
# Install the lightweight Kubernetes server
curl -sfL https://get.k3s.io | sh -

```

**3. Install Terraform:**

```bash
# Install necessary dependencies
sudo apt-get install -y gnupg software-properties-common curl

# Add HashiCorp GPG Key
curl -fsSL https://apt.releases.hashicorp.com/gpg | sudo gpg --dearmor -o /usr/share/keyrings/hashicorp-archive-keyring.gpg

# Add the official HashiCorp repository
echo "deb [signed-by=/usr/share/keyrings/hashicorp-archive-keyring.gpg] https://apt.releases.hashicorp.com $(lsb_release -cs) main" | sudo tee /etc/apt/sources.list.d/hashicorp.list

# Update and install Terraform
sudo apt-get update && sudo apt-get install terraform

```

## Project Structure

* `/terraform`: A folder containing your Terraform configuration files (`*.tf`).
* `/pipelines`: The folder containing your model training pipelines.
* `install_terraform.sh`: A shell script in the root directory that verifies Terraform within your WSL environment.
* `Dockerfile`: A Dockerfile in the root directory to build your Rossmann API image.
* `run_all.bat`: The main Windows batch script that orchestrates the entire deployment.

## How to Run the Pipeline

1. Open your project directory in Windows Explorer.
2. Ensure **Docker Desktop** is currently running in the background.
3. Right-click the `run_all.bat` file and select **"Run as Administrator"**.
* *Administrator privileges are required because the batch script manages WSL instances, Docker daemons, and storage mounts.*



## What the Script Does

1. **Environment Check:** Validates that WSL and Docker are installed and active.
2. **K3s Initialization:** Safely shuts down ghost WSL processes and starts a native K3s server within Ubuntu.
3. **Image Management:** Pulls necessary infrastructure images (Postgres, Redis, MLflow, Prefect) and builds/imports your custom Rossmann API image directly into the K3s cache.
4. **Terraform Orchestration:** Initializes and applies your Terraform configuration (`terraform apply -auto-approve`) to deploy all services.
5. **Monitoring:** Automatically opens separate terminal windows providing live logs and local port forwarding for the API, MLflow, Prefect, and the Database.

## Troubleshooting

* **"K3s did not come up after 2 minutes":** Ensure you have sufficient RAM allocated to WSL. You can configure this by creating a `.wslconfig` file in your Windows User profile folder to assign more memory.
* **"Docker build failed":** Ensure your `Dockerfile` is present in the root directory, correctly named, and contains no syntax errors.
* **"Terraform command not found" (Inside the script):** Ensure you successfully completed Step 3 in the Ubuntu terminal and restarted the terminal afterward.
* **Permission Denied Errors:** Ensure you are running `run_all.bat` as Administrator.
